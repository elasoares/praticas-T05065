## 📚 Sobre o curso

Neste curso aprendemos do zero a construir um página web usandos as três linguagens principais do front-end:

|Linguagem|O que faz|
|---------|---------|
| HTML | A estrutura da página|
| CSS | O visual |
| JavaScript | A interatividade|
